- Fixed in this PR (lockfile only, no code change): `rustls` → 0.23.46, `rustls-webpki` → 0.103.15, `quick-xml` → 0.39.4. `rustls` carries the DTLS handshake, so this matters.

- Major upgrades: none checked in detail (`cargo outdated` missing); `netdev` 0.43 and `webrtc-dtls` 0.12 are the ones to watch.
- GitHub Actions: all current majors except `actions/cache@v4` and `actions/setup-python@v5` (minor lag, low risk).
- Secrets: grep for key, token and password patterns found only secret names in workflows and docs, no values. No gitleaks run.
